# 📊 Exploratory Data Analysis (EDA) Project

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on datasets to uncover patterns, trends, correlations, and insights using Python.

The application is built using **Streamlit** for an interactive dashboard and uses powerful data analysis libraries like Pandas, Matplotlib, Seaborn, and Plotly.

---

# 🚀 Features

✅ Upload CSV datasets  
✅ Display dataset preview  
✅ Statistical summary of data  
✅ Data cleaning and handling missing values  
✅ Correlation heatmap visualization  
✅ Histogram and distribution analysis  
✅ Scatter plot analysis  
✅ Interactive dashboard using Streamlit  
✅ Generate insights from data  

---

# 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly
- Streamlit
